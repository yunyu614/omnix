## 二、长版正文

**【Omnix · 奥米】模块仓库与玩机工具箱**

每次装模块都要：开管理器 → 找群文件 → 下 zip → 回管理器刷入，来回跳四五次。
所以我自己写了一个，把这条链路塞进一个 App 里。

体积 9MB，无广告、无后台常驻、不采集任何数据，代码开源。

### 🧩 模块仓库：一次搜完所有源
- **KernelSU 官方**（modules.kernelsu.org）
- **KernelSU-Next / Magisk Alt Repo / Xposed 模块组织** 聚合
- **LSPosed 官方**，1400+ 模块分页全量读取，不是只给你看第一页那 30 个
- 每条标明来源仓库，支持搜索、按热度/版本排序
- 下载完直接弹窗：显示保存路径 → 一键安装 / 刷入

### 📦 已安装模块：分开看，能动手
- **Root 模块**（KSU / Magisk / APatch）与 **Xposed 模块** 分组，不再混在一起
- Xposed 模块按 LSPosed 数据库识别，识别率和管理器一致
- 详情页可：禁用/启用、运行模块的 `action.sh`、卸载
- 像清理类模块那种会自己更新描述的，这里也能看到最新状态

### 🛠 系统工具
- **应用冻结**：含系统应用，一键 disable / enable
- **镜像分区**：167+ 分区，导出 `.img`，刷入时**区分 A/B 槽**并提示当前活动槽
- **应用备份**：自选应用导出安装包，含 split APK
- **字库备份**：关键分区 / 完整备份两档，带容量预估
- **机型伪装**：品牌型号指纹一键改，自动备份原值可还原
- **刷入 LSPosed**：内置模块包，可选附带 Zygisk Next
- **应用收录**：Shizuku / Termux / MT 管理器 / Scene 等

### 🎨 外观
- 8 套配色：雾泉 / 青瓷 / 暮云 / 樱粉 / 琥珀 / 摩卡 / 石墨 / 深海
- 日间 / 夜间 / 跟随系统，全站磨砂玻璃
- **桌面图标跟着主题变**（8 套自适应图标）
- 浮岛式底栏，可切停靠

### ⚠️ 使用前必读
1. **需要 Root**（KernelSU / KernelSU-Next / Magisk / APatch 都行）
2. 刷模块、写分区、冻结应用、伪装属性都是高危操作，**先备份**
3. 部分功能看机型：比如分区刷入依赖 `by-name` 节点，机型不支持会明确告诉你，不会假装能用
4. 首次启动有免责声明，同意后使用
