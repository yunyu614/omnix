# Omnix 交流群 · 群公告

群里主要聊 **Omnix（奥米）** 这个 App 和 Android 玩机相关的事。

---

## 一、群定位
- Omnix 使用答疑、问题反馈、版本内测
- KernelSU / LSPosed / Magisk 模块相关交流
- 刷机、分区、伪装等玩机经验分享

## 二、下载与更新
- 最新版本只发在 **GitHub Releases**：github.com/yunyu614/omnix/releases
- 群文件 / 群相册只放说明与截图，不放来路不明的 APK
- 有人私聊发你「Omnix 内测版」一律不要装

## 三、提问前请先做三件事
1. 说清机型和系统版本（例：Redmi K70 Pro / 澎湃 OS 2.x）
2. 说明用的是哪个 Root（KernelSU / KernelSU-Next / Magisk / APatch）及版本
3. 把报错截图或日志发出来（设置 → 权限管理 里能看到当前授权状态）

**「用不了」「打不开」这种一句话提问，基本没法排查。**

## 四、群规
- 禁止广告、拉人、发无关链接、发盗版资源
- 禁止讨论违法内容；模块只从官方仓库或原作者渠道获取
- 禁止刷屏、恶劣人身攻击；技术争论可以，别带情绪
- 私加好友发广告 → 直接踢

## 五、免责
- 刷入模块、写分区、冻结应用、伪装属性都是高危操作，**后果自负**
- 群管理和开发者不对任何设备损坏、数据丢失负责
- 动手前请先备份，尤其是「字库备份」和分区导出

## 六、支持开发者
App 内「设置 → 打赏与交流群」有赞赏码，金额固定 ¥5，自愿，不影响任何功能。
